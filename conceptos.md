## 2. Conceptos básicos de Git y GitHub

### Elementos y Estructuras
* **Repositorio:** Carpeta o almacén donde se guardan todos los ficheros del proyecto (código, documentación, ejemplos). Puede ser **público** o **privado**.
* **Archivo README (`README.md`):** Fichero inicial que contiene las instrucciones básicas del repositorio: nombre, descripción, índice de contenidos, uso y licencia.
* **Rama (Branch):** Copia paralela del contenido de un proyecto para trabajar de forma aislada sin comprometer el código principal.
  * **Rama master/main:** Contiene el proyecto original o versión estable.
  * **Rama feature:** Copia local offline para avanzar en una funcionalidad o mejora específica.

### Acciones e Instantáneas
* **Clone:** Copia local de un repositorio remoto para trabajar de forma offline en tu equipo.
* **Fork:** Copia de un repositorio realizada directamente en tu perfil de GitHub para trabajar online de forma independiente.
* **Commit:** Instantánea o registro guardado localmente que almacena los cambios realizados (modificaciones, adiciones o borrados de líneas).
* **Push:** Acción de enviar tus commits locales hacia el repositorio remoto.
* **Pull Request (PR):** Solicitud formal mediante la interfaz gráfica para proponer e integrar tus cambios en la rama principal tras una revisión.
* **Merge:** Proceso de fusión que integra los cambios de una rama en otra (por ejemplo, de una rama remota a `master`) actualizando ambas partes.
