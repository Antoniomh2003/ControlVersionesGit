# 3. Lenguajes de marcas: Markdown

## ¿Qué es Markdown?
Markdown es un lenguaje de marcado ligero que facilita la aplicación de formato a un texto plano mediante caracteres especiales[cite: 8].

- **Origen:** Creado en 2004 por John Gruber[cite: 8].
- **Propósito inicial:** Nació como una herramienta para convertir texto plano a HTML de forma rápida y limpia[cite: 8, 19].
- **Filosofía:** Diseñado para ser fácil de escribir y, sobre todo, altamente legible tanto en su formato original como renderizado[cite: 8].
