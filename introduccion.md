# Ud2.- Git, Markdown y GitHub

## Introducción

En el desarrollo de proyectos técnicos y software, la colaboración eficiente depende de tres pilares esenciales:

* **Sistema de control de versiones (Git):** Permite registrar el historial de cambios, trabajar de forma distribuida y recuperar versiones previas con total seguridad.
* **Lenguaje de marcas (Markdown):** Ofrece un método sencillo y legible para redactar y estructurar documentación técnica a partir de texto plano.
* **Plataforma de publicación y alojamiento (GitHub):** Actúa como repositorio central en la nube, conectando equipos y facilitando el flujo de colaboración.

A lo largo de esta unidad analizaremos en detalle cada una de estas herramientas, su integración y los flujos de trabajo esenciales para gestionar proyectos de manera profesional.
